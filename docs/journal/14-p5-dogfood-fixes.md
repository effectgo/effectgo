### Dogfood fixes (P5)

Branch `feat/dogfood-fixes`, from `integrate/docs` (aa945ee). The input is the FRICTION log of a 2.2k-line stdlib-only service written in contract mode (`reservations`, entries 11, 14, 16 and 24). Each fix is pinned by a test, and the run below checks the corpus and the real-world oracle for regressions.

**Named results and defers (seq 14).** The SSA engine kept a named result in an `*ssa.Alloc`, and a `return` read the alloc's union of every store. A deferred closure that reads the result (the rollback guard) therefore widened every return to the raw driver errors. The fix reads the result at each return: the value stored by the return, plus the closures' writes, which run after it. A deferred closure that only reads the result reads that value. A load in the declaring function reads the store that reaches it along a straight chain of blocks, so `if err = f(); err != nil { return err }` returns `f`'s set. The fallbacks to the union are an escaped address (adds `?`), a `recover` in the unit, a join without a store, and a closure that is not deferred. The AST engine is unchanged. Files: `errset/ssadefer.go` (new), `errset/ssa.go`, `errset/ssaflow.go`. Tests: `errset/testdata/src/deferflow` (the repro, the Hold shape, the wrap-in-defer write with `%w` and with `%v`, an overwrite, a naked return, an escaped address, `recover`, and a return of the variable itself), run by `TestSSADeferredNamedResults`. The effects analyzer has no variable-level union (its effects come from calls), so it has no analogous over-approximation.

**Package defaults and test files (seq 16).** `//effectgo:package` no longer applies to a function declared in a `_test.go` file. The function's own directive still does. Files: `effects/effects.go` (`funcContracts`). Tests: `effects/pkgdefault_internal_test.go` (a table test is silent under a `pure` default, an explicit `//effectgo:pure` in a test file is kept, and a library function still takes the default). End to end, `go vet -vettool` on a scratch module flags the table test with the baseline binary and not with the new one, and still reports the explicit directive in the test file.

**net/http writers (seq 24).** Added `ResponseWriter.Write` and `WriteHeader` (net), `Flusher.Flush` and `Hijacker.Hijack` (net), `http.Error`, `NotFound` and `Redirect` (net), `ServeFile` (fs and net), and `ServeContent` and `ServeFileFS` (net and unknown, because the content reader is the caller's). Each has a `file:line` citation to Go 1.26.9. Files: `stubs/stdlib.stubs`. Test: `effects/testdata/src/httpw` through `TestShippedHTTPRules`.

**Stub duplicates (seq 11).** Two decisions. A project or explicit rule now **replaces** a shipped rule for the same target, which is what errset already did for the `errors` verb (the later rule wins); within one layer, a duplicate is still an error and names the first definition. A standalone run checks the stub files once before the analyzers start, so a bad rule prints one line (`effectgo: <file>:<line>: ...`) and the run exits 1. Before, it printed the error once per package and a `failed prerequisites` line for every dependent. Files: `effects/stubs.go` (layered `loadStubs`, `CheckStubs`), `internal/stubs/discover.go` (`IsShipped`, `Where`), `cmd/effectgo/stubcheck.go` (new), `cmd/effectgo/main.go`. Tests: `effects/stubs_internal_test.go`, `cmd/effectgo/stubcheck_test.go`. A module below the working directory that no pattern names still reports per package, and a `go vet` run is one process per package, so each reports its own error; both are documented in the stub reference.

- **Mutants** (read-only, the new binary): 1 to 7 are caught with the findings the mutant log records (for example `Hold is declared //effectgo:pure but has effect time via Hold → stamp → roundToNow → time.Now` for 1, and `missing cases in switch on Status: StatusArchived` for 5). Each exits 3. Mutant 8, the control, exits 0.
- **Examples**: `examples/run.sh` exits 0, and its output is identical to the baseline tree's.

### What did not change

The effects analyzer, the Gin and Huma adapters and the OpenAPI output are unchanged except through the net/http rules and the errset engine. The AST engine keeps the union for named results; the SSA engine is the default and the only one with the new reads.
